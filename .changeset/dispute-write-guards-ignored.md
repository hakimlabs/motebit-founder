Every dispute verdict writer is now guarded on state (dispute-v1 §6.6, design `docs/proposals/dispute-money-path-v1.md` M6, PR 2). The round-1 commit, `finalizeFederationResolution`, moved a dispute to `resolved` from whatever state it found: a `final`, `resolved`, `appealed`, `opened` or `expired` dispute with no round-1 row was moved back to `resolved`. It now commits only `WHERE state IN ('evidence','arbitration')`. When its verdict does not commit, it writes nothing and returns the record that stands: the dispute's state and its committed round-1 resolution. It is round 1 only. Its round-2 branch, which moved a dispute to `final` without running the fund action, is gone, and a round-2 call throws. Round 2 commits only through `commitRound2Verdict`, which is guarded on `appealed` and runs the fund action in the same transaction. The deferred orchestration worker's round-2 path now calls `commitRound2Verdict`. No orchestration row for round 2 is created today, so that path is not yet reached. It is the round-2 retry once `/appeal` defers below quorum. `POST /api/v1/disputes/:disputeId/resolve` answered 200 with a verdict it had not persisted when the verdict lost a concurrent commit by another process or by the worker. It now answers 409 `DISPUTE_RESOLUTION_NOT_COMMITTED` with the standing `state` and `resolution`, on the single-relay and synchronous federation paths. The lazy expiry on `GET /api/v1/disputes/:disputeId` wrote `expired` keyed on the dispute id alone. A dispute another process had moved out of `opened` between the read and the write was expired anyway. The write is now guarded `AND state = 'opened'`, and a lost race reports the state that stands. On the single-relay path, `/resolve` answers 200 only when the caller's verdict is the one recorded. That is the same outcome, with the same fund action and split derived from the §7.2 table, whether the call is a re-POST, a concurrent call or a lost race. Any other body gets 409 with the standing record. Before this, the in-process collapse and the cached path answered a different verdict 200 with the recorded one. The standing record reports the governing resolution: round 2 when one was committed, else round 1. The worker commits a round-2 verdict only on quorum. A round 2 that timed out below quorum writes nothing and the dispute stays `appealed`. Before this, its 0.5 split moved money over a signed round-1 verdict.
